# Archive

Old planning notes and audit write-ups, kept for history.

Early on I wrote some of this as if Swing Desk might turn into a product, so you will see a PRD, a ship plan, an org table and a go-live audit. It never went that way. Swing Desk is a personal research desk that I run on my own machine for my own trading, with no users other than me and no order execution.
